## 3. Brand Color System (The Terminal Minimalist: Carbon & Emerald Mint)

### Color Palette Tokens

| Role | Color Name | Hex Code | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Background** | Pitch Carbon | `#09090B` | Main background for website, videos, slides, and thumbnails |
| **Surface / Container** | Dark Zinc | `#18181B` | Code blocks, cards, borders, and UI containers |
| **Border / Divider** | Subtle Zinc | `#27272A` | Structural outlines, card dividers, and subtle grid lines |
| **Primary Accent** | Precision Emerald | `#10B981` | Primary brand accent, active states, key terminology, and CTA buttons |
| **Secondary Accent** | Mint Highlight | `#34D399` | Secondary nodes in diagrams, glow effects, and hover highlights |
| **Primary Text** | Crisp White | `#FAFAFA` | Main headings, title copy, and high-priority code syntax |
| **Secondary Text** | Neutral Zinc | `#A1A1AA` | Subheadings, descriptions, metadata, and code comments |

### Application Guidelines

* **Thumbnails & Social Covers:** Maintain a `#09090B` carbon background. Use `#FAFAFA` for bold headline typography and isolate key high-value concepts in `#10B981` (Precision Emerald) to draw visual focus.
* **Architecture Diagrams:** Nodes and containers use `#18181B` with `#27272A` borders. Active execution paths and data flows illuminate in `#10B981` and `#34D399`.
* **Code Presentation:** Code cards rest on `#18181B` surfaces with a 1px `#27272A` border. Syntax highlighting pairs clean white variables with emerald keywords and mint strings.
* **Web Interface:** Dark-mode native interface with `#10B981` interactive elements and subtle ambient emerald glow on active cards.
